# 润 Nirun

桌面自由倒计时：今天还剩多久、距离辞职还有多久，以及今天已经赚到多少。

## 下载

到 [Releases](https://github.com/Yee128Chen/nirun-releases/releases/latest) 下载最新版：

- **Windows 10/11**：`Nirun_0.1.4_x64_setup.exe`
- **macOS（Apple Silicon / M 系列）**：`Nirun-0.1.4-arm64.dmg`
- 免安装 Windows 版：`Nirun-0.1.4.exe`

## 安装

**Windows**：双击安装包，按向导完成设置。

**macOS**：打开 dmg，把「润 Nirun」拖进「应用程序」。第一次打开时右键 App → 打开 → 再点「打开」。如果提示「已损坏」：

``bash
xattr -dr com.apple.quarantine "/Applications/润 Nirun.app"
``

## 数据

工资、目标、照片只保存在本机，没有账号、没有云同步。覆盖安装不会清空设置；换电脑需要重新设置。

## 更新

每次发版会在 Releases 更新。下载新版本后直接覆盖安装即可。
